# Файлы отображения отчётов "Карта ГПР" и "Внешние участники проекта" на форме
В данном репозитории находятся HTML и JS файлы по отрисовке и отображению отчётов "Карта ГПР" и "Внешние участники проекта" на форме сущности среды Dynamics 365. 

**Архив имеет следующее содержимое:**
- loyality_graph.html - Файл HTML, содержащий отображение отчёта "Карта ГПР"
- loyality_graph_logic.js - Файл JS, содержит логику отрисовки отчёта "Карта ГПР" в файле loyality_graph.html на основе полученных с формы данных
- project_formevents.js - Файл JS, содержит логику основного скрипта формы сущности ответственной за передачу контекста с данными в отчёты "Карта ГПР" и "Внешние участники проекта"
- report_view.html - Файл HTML, содержащий отображение отчёта "Внешние участники проекта"
- report_view.js - Файл JS, содержит получения отчёта "Внешние участники проекта" с сервера отчётов и его отбражении в файле report_view.html
